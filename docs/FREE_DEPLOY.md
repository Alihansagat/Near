# Бесплатный доступ с двух телефонов

Для iPhone и Android удобнее всего использовать веб-версию как PWA: открыть ссылку в браузере и добавить её на главный экран. Данные синхронизируются через общий API.

1. Создайте бесплатный PostgreSQL-проект в Neon и скопируйте `DATABASE_URL`.
2. Создайте бесплатный web service на Render из этого репозитория. Blueprint `render.yaml` уже задаёт сборку, миграции и проверку `/health/`.
3. В переменных Render укажите `ALLOWED_HOSTS` (домен Render) и временно `CORS_ALLOWED_ORIGINS` (домен будущей веб-версии).
4. В GitHub Pages включите Pages из Actions и добавьте repository variable `API_BASE_URL` со значением `https://ВАШ-RENDER-ДОМЕН/api/`. Workflow `.github/workflows/flutter-web.yml` соберёт Flutter web для адреса `https://alihansagat.github.io/Near/`.
5. После публикации Pages добавьте её адрес в `CORS_ALLOWED_ORIGINS` на Render и перезапустите сервис.
6. Откройте ссылку Pages на обоих телефонах, зарегистрируйте два аккаунта и соедините их кодом приглашения.

Для фото, видео и аудио задайте S3-совместимое хранилище (например, Cloudflare R2) через `S3_BUCKET`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` и `AWS_S3_ENDPOINT_URL`. Это нужно, потому что локальный диск бесплатного Render временный.

Вариант только для Android — собрать APK и передать файл напрямую. Для двух разных iPhone постоянная бесплатная установка через App Store невозможна без Apple Developer Program, поэтому PWA подходит лучше.

## Обновление: фото и новые разделы

Без S3 файлы теперь сохраняются приватно в PostgreSQL/Neon, а не на временном диске Render. Общий лимит вложений — 200 МБ; при заполнении новые загрузки отклоняются понятной ошибкой. Доступ к файлам по-прежнему проверяет участника пары. Для большого архива видео нужно S3/R2; бесплатная база не является безлимитным медиахранилищем. Миграция переносит файлы, которые ещё доступны на локальном диске; файлы, утраченные при прошлых перезапусках Render, восстановить нельзя.

Apart / Together считает завершённые календарные дни с момента выбора режима, в часовом поясе пары. Переключение в тот же день меняет текущую запись; дни до первого выбора не добавляются. Near Recap по умолчанию показывает последний законченный месяц, также доступен текущий месяц.

Важные даты показывают напоминания внутри приложения. Кнопка Add reminders to calendar выгружает ICS: пользователь импортирует его в календарь и разрешает уведомления. Экспорт включает 5 лет ежегодных дат и 36 месячных годовщин. После изменения дат следует обновить события в календаре: автоматической синхронизации и фонового web push нет.

Объятия проверяются каждые 20 секунд при открытом приложении и при возвращении к нему. Сохранённый курсор исключает повторный показ последнего объятия на том же устройстве.

Вопросы создаются при открытии нового дня без внешнего AI и расписания. Подготовленный набор содержит 1 920 вариантов на категорию (с сентября 2026); после исчерпания не зацикливается. Ответы и ранее сохранённые выбранные вопросы не переписываются.

Карта использует OpenStreetMap с указанием авторства, поддерживает масштаб, перемещение, вращение и отметки. Это не Apple Maps. Шрифт emoji Apple используется там, где его предоставляет устройство; шрифт Apple не поставляется для Android.
