Near бесплатно на каждом iPhone.
Без Expo и без подписки.

1

Откройте Near в Safari кнопкой ниже.

2

Нажмите «Поделиться» — квадрат со стрелкой вверх — затем «На экран “Домой”».

3

Нажмите «Добавить». Откройте иконку Near и войдите в свой существующий аккаунт.

Открыть Near

Повторите на втором iPhone. Это веб-приложение, которое открывается отдельным окном с главного экрана. Интернет нужен; компьютер можно выключить.
